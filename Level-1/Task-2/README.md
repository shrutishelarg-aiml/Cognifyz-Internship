# Level 1 - Task 2: Descriptive Analysis

## Objective

The objective of this task is to perform descriptive analysis on the restaurant dataset by calculating statistical measures for numerical features and exploring the distribution of important categorical variables.

## Dataset

The dataset contains information about restaurants, including their location, cuisines, ratings, pricing, and other attributes.

## Tasks Performed

### 1. Statistical Analysis
- Calculated summary statistics for numerical columns.
- Computed:
  - Mean
  - Median
  - Standard Deviation
  - Minimum Value
  - Maximum Value
  - Quartiles

### 2. Categorical Variable Analysis
Analyzed the distribution of:
- Country Code
- City
- Cuisines

### 3. Top Cities Analysis
- Identified cities with the highest number of restaurants.
- Visualized the top 10 cities using bar charts.

### 4. Top Cuisines Analysis
- Identified the most common cuisines in the dataset.
- Visualized the top 10 cuisines using bar charts.

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Findings

- The dataset contains restaurants from multiple cities and countries.
- Some cities have significantly more restaurants than others.
- A few cuisines dominate the dataset and appear more frequently.
- Statistical summaries provide insights into restaurant ratings, costs, and customer votes.

## Visualizations

The following visualizations were created:
- Country Code Distribution
- Top 10 Cities by Restaurant Count
- Top 10 Cuisines by Restaurant Count

## Conclusion

Descriptive analysis helped in understanding the structure of the dataset and identifying important patterns in restaurant locations and cuisines. These insights form the foundation for further analysis and advanced data science tasks.
