# Level 1 - Task 3: Geospatial Analysis

## Overview

This task focuses on analyzing the geographical distribution of restaurants using latitude and longitude coordinates. The objective is to visualize restaurant locations, understand their distribution across cities and countries, and explore the relationship between location and restaurant ratings.

## Objectives

- Visualize restaurant locations using latitude and longitude data.
- Analyze the distribution of restaurants across different cities and countries.
- Investigate whether restaurant location has any impact on ratings.
- Generate visualizations to better understand geographical patterns.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Folium
- Google Colab

## Analysis Performed

### 1. Location Visualization
- Used latitude and longitude coordinates to plot restaurant locations on a map.
- Created an interactive map for geographical exploration.

### 2. City-wise Distribution Analysis
- Identified cities with the highest number of restaurants.
- Visualized restaurant distribution across major cities.

### 3. Country-wise Distribution Analysis
- Analyzed the number of restaurants present in different countries.
- Compared restaurant concentration across countries.

### 4. Rating vs Location Analysis
- Examined the relationship between restaurant ratings and geographical location.
- Explored whether highly rated restaurants are concentrated in specific areas.

## Key Findings

- Restaurants are concentrated in a few major cities.
- Certain countries contribute a large portion of the dataset.
- Restaurant ratings vary across different locations.
- Geographical analysis provides useful insights into restaurant distribution patterns.

## Conclusion

Geospatial analysis helped visualize restaurant locations and understand their distribution across cities and countries. The analysis also provided insights into how restaurant ratings vary across different geographical regions.
